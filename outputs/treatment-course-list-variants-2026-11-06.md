# Курсы — варианты основного списка

[Сравнение в Figma](https://www.figma.com/design/tAZysbFzUOJg6xv4iN6YU7/?node-id=1084-21844).

Отрисован один основной экран вкладки в трёх вариантах, по 390×844. Источник оформления — выбранная пользователем «Лечение / Основа», 1068:21773. Содержание и course card взяты из архивного списка 723:3928. Основа и архив не изменялись.

- A — подробные карточки: видна схема каждого препарата, у конечного курса — день курса и полоса длительности. Нужна небольшая прокрутка.
- B — компактный список: название, получатель, сроки или цикл, краткий состав, актуальный этап цикла и предупреждения о запасе. Три активных курса и вход в завершённые помещаются в показанный экран.
- C — группировка по людям: те же компактные карточки под «Я» и «Мама», без повторения имени внутри. Имена групп отделены от предыдущего блока большим отступом и приближены к своим карточкам.

Во всех вариантах сохранены общий выбор человека в заголовке, кнопка «+», «Сегодня / Курсы», нижняя навигация, шрифты Manrope / SF Pro, фон и белые карточки. Никаких новых видов кнопок. Week относится к ежедневному расписанию и не переносился в список курсов. Завершённые свёрнуты в одну строку «Завершённые · 2», без отвлекающих карточек.

Из архива перенесены получатель, сроки и схемы, краткий состав, предупреждения о запасе. Показатели «Принято X из Y» убраны из обзорного списка: для оценки фактов есть ежедневный экран и будущая история. Полоса в A показывает длительность конечного курса; у циклического и постоянного её нет. Для цикла подписан текущий период приёма.

Предлагаю начать с B: для обзорного списка он сохраняет основные признаки курса и занимает меньше места. A подойдёт, если важно сверять схему прямо в списке. C — если основная задача состоит в ведении нескольких людей. Это проектные гипотезы, не результаты тестирования.

Ограничение текущего объёма: не добавлены экраны отдельного курса, создания, завершённых и модальные окна. Сделана нативная вертикальная прокрутка списка и переход вкладкой «Сегодня» к выбранной основе; остальные действия пока являются точками входа для дальнейшей работы.

Проверено: три активных курса во всех вариантах; прогресс только у конечного курса в A; отдельное отображение текущего этапа цикла; отступ под групповыми заголовками 8; соответствие шрифтов; интерфейс из редактируемых слоёв и существующих instances, растровых UI внутри нет. Проведена визуальная проверка всей композиции.
