## Как идём

Порядок: **исследование → макет → код**. Вывод из таблицы становится решением в макете, а решение из макета — кодом. Если что-то меняется на позднем шаге (например, в коде выяснилось, что макет не учёл состояние), записываем это на шаге раньше, в разделе «Чего не хватает»/«Открытые вопросы».

Связи записываем ссылками, чтобы по любому месту можно было найти два других:

- строка таблицы → `«Лист», B7` (как в [treatment-ux-review](../treatment-ux-review-2026-11-05.md));
- кадр Figma → узел `1186:21990`;
- код → путь к файлу `lib/features/...`.

## Правила для этих файлов

- В начале сессии прочитать этот файл и файл того места, где работаем.
- В конце сессии: обновить «Где остановились», отметить сделанное в файле места, добавить строку в журнал ниже.
- Решение пользователя записывать с датой: «решение пользователя 2026-11-18».
- Не выдумывать: если что-то не проверено (лист не открывали, кадр не смотрели), так и писать — «не проверено».
